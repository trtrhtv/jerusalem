# ירושלים בשכבות זמן · Jerusalem in Layers of Time

הדמיה מעוגנת-מקורות של ירושלים על פני הזמן — גוללים על ציר זמן ורואים איפה
העיר הייתה בנויה בכל תקופה, מתי נבנה כל אזור ואיזה טיפוס בנייה היה בו. **כל
אלמנט ויזואלי נושא מדרג ראיות גלוי, ואסור לזייף ודאות** — זו מטרת-העל של
הפרויקט, לא הערת שוליים.

> A source-anchored visualization of Jerusalem across time. Drag a timeline and
> watch the city fill in — every element carries a visible **evidence tier** and
> its **sources**. Integrity is the headline feature: we never fake certainty.

---

## החזון · Vision

אפליקציית ווב בשני מצבים:

1. **מבט-על ("העיר נבנית")** — מפה אינטראקטיבית עם ציר זמן. גוררים את הזמן,
   גושים ומבנים מופיעים לפי תקופת בנייתם; קליק על אלמנט = תקופה + טיפוס +
   המקורות שעליהם הוא נשען. **זה ה-MVP שממומש כאן.**
2. **מצב הליכה** (עתידי) — תנועה ברחוב בתוך הדמיה תלת-ממדית low-poly של התקופה,
   בסגנון Street View, מעוגנת בגבהי מבנים אמיתיים שחולצו מתצ"א היסטורי.

בכל נקודת עוגן שבה קיים מקור אמיתי, המשתמש יוכל להחליק בין ההדמיה למקור
("ההדמיה בנויה על התצלום הזה מ-1898 / על פסיפס מידבא מהמאה ה-6"). כרגע, בהיעדר
אירוח של הנכסים, כל אלמנט מקשר החוצה אל הארכיון/המוסד המחזיק במקור.

## מדרג הראיות · Evidence tiers (העיקרון המרכזי)

כל אלמנט מסומן באחת משלוש דרגות, גלויה תמיד במקרא ובכרטיס הפירוט:

| דרגה | Tier | משמעות |
| --- | --- | --- |
| 🟢 **מתועד** | documented | קיים מקור ישיר: תצלום, מפה, שריד חפור או דגם מחקרי. |
| 🟠 **טיפולוגי** | typological | המבנה הספציפי אינו ידוע, אך ידוע טיפוס הבנייה של האזור באותה תקופה. |
| 🔴 **השערה** | conjecture | מילוי סביר בהיעדר עדות, מסומן במפורש ככזה. |

**הפרדה חשובה:** `evidenceTier` מתאר את הוודאות לגבי *קיום/תקופה/טיפוס*, ואילו
`geometryConfidence` מתאר בנפרד את הוודאות לגבי *הצורה המצוירת*. תאריך ייסוד יכול
להיות מתועד היטב בעוד המצולע שציירנו עדיין מקורב — ואנחנו לא מטשטשים את ההבדל.

## מצאי מקורות · Source inventory

מנוהל ב-[`data/sources.json`](data/sources.json). זכויות אומתו (יולי 2026):

- **עות'מאנית מאוחרת (1840–1917):** מדידת וילסון 1865, תבליט אילש 1873 (1:500),
  ליתוגרפיות דיוויד רוברטס (1842–49), ארכיון הצילום של המושבה האמריקאית /
  Matson, תצ"א גרמני 1917/18.
- **ממלוכית (1250–1517):** סקר בורגוין *Mamluk Jerusalem* (רפרנס מחקרי); מארג
  הרחובות קיים עד היום.
- **ביזנטית (330–638):** מפת מידבא (מראה את הקארדו), הקארדו החפור.
- **בית שני (עד 70 לספירה):** רחוב עולי הרגל החפור, הרובע ההרודיאני, דגם הולילנד.
- **בסיס עכשווי:** OpenStreetMap (ODbL).

## זכויות · Rights (קריטי)

- **תצלומים / חריטות / מפות עד ~1928** → נחלת הכלל, שימוש ישיר.
- **שחזורים ודגמי VR מודרניים** → קניין יוצריהם. משמשים **כרפרנס מחקרי בלבד**
  לבניית הדמיות משלנו — לא כנכסים להעתקה/אירוח. מסומנים `reference-only`.
- **Google Street View** → מותר להטמיע (embed), אסור לארח מחדש. **Mapillary** פתוח.

כל מקור ב-`sources.json` נושא שדה `rights` מפורש, ובכרטיס הפירוט מוצג תג הזכויות.

## אמיתות שנשמרות (בלי הבטחות שווא)

- הליכה פוטוגרפית רציפה בעבר **לא קיימת** — איש לא צילם פנורמות רחוב ב-1926.
  לפני עידן Street View זו הדמיה תלת-ממדית, לא תצלומים.
- מתצ"א היסטורי בזוגות סטריאו אפשר לחלץ **גבהי מבנים אמיתיים** לעיר low-poly.
- "עיר שלמה הליכתית בכל תקופה" היא עבודת שנים. בונים ציר אחד קודם, טוב, ומרחיבים.
  **מקטע אחד אמין > עיר שלמה מזויפת.**

## שלבי בנייה · Build phases

1. **שלד נתונים** — שכבת מבנים × תקופת-בנייה × טיפוס (OSM + טבלת ייסוד השכונות
   + דיגיטציה של מפות היסטוריות מיושרות). → *סכמה + דאטה ראשוני מומשו.*
2. **MVP — מפת ציר-זמן ("העיר נבנית")** — גורר זמן, מבנים מופיעים לפי תקופתם,
   קליק = תקופה + טיפוס + מקור. → **מומש (אזור הפיילוט).**
3. **פיילוט הליכה תלת-ממדית** באזור מתועד היטב. אזור: ציר שער יפו–רחוב יפו
   (מכוסה בכל המפות והתצלומים 1865→היום). תקופת פתיחה: עות'מאנית ~1870. → *עתידי.*

### מצב נוכחי · What's built

- ✅ סכמת JSON למבנה/גוש: `{ id, geometry, builtPeriod, buildingType, evidenceTier, sources[] }`
  ([`data/schema/feature.schema.json`](data/schema/feature.schema.json)), עם
  הרחבות יושרה: `geometryConfidence`, `builtYear`, `demolishedYear`.
- ✅ דאטה ראשוני אמיתי לאזור הפיילוט **שער יפו–רחוב יפו**
  ([`data/features/jaffa-gate-corridor.json`](data/features/jaffa-gate-corridor.json)) —
  10 אלמנטים מתוארכים ומתועדים (שער יפו 1538, מגדל דוד, פרצת 1898, מגדל השעון
  העות'מאני 1908–1922, רחוב יפו, ומשכנות שאננים / מחנה ישראל / נחלת שבעה / מגרש
  הרוסים / ממילא). **אין נתונים מומצאים** — חורים מסומנים כ"טיפולוגי".
- ✅ מפת ציר-זמן אינטראקטיבית (MapLibre GL) עם מקרא מדרג ראיות קבוע, סרגל זמן
  (1500–1930), וכרטיס פירוט עם עוגני מקור וזכויות.
- ✅ **נקודות מצלמה (עוגני מקור חזותיים)** — 5 תצלומים/ליתוגרפיות אמיתיים
  ומאומתים של הציר ([`data/viewpoints.json`](data/viewpoints.json)): רוברטס 1839,
  כניסת וילהלם השני 1898 (מתעדת את הפרצה), רחוב יפו בתהלוכת 1898, שער יפו
  1898–1914, ומבט ממגדל השעון (1908–1922). אייקון 📷 על המפה מופיע משנת יצירת
  התמונה — לפני 1839 אין תיעוד חזותי, והמפה מציגה זאת בכנות. קליק פותח את רשומת
  הפריט המאומתת בספריית הקונגרס. התמונות אינן מאוחסנות אצלנו; מיקומי המצלמה
  מוערכים ומסומנים ככאלה.
- ✅ שער יושרה: `npm run validate` מוודא שכל אלמנט תואם לסכמה, שכל מקור מצוטט
  קיים, ושכל נקודת מצלמה מפנה למוסד מוכר.

## אזור הפיילוט · Pilot area

**ציר שער יפו–רחוב יפו** נבחר כי הוא מכוסה בכמעט כל מקור פתוח: מדידת וילסון
1865, תבליט אילש, תצלומי המושבה האמריקאית ותצ"א 1917/18. תקופת הפתיחה היא
עות'מאנית מאוחרת (~1870) — שם המקורות הכי חזקים — ומשם אחורה.

## סטאק · Stack

- **Next.js 16** (App Router, TypeScript) · **Tailwind CSS v4**
- **MapLibre GL** — מפה וקטורית/ראסטר; בסיס OSM (ODbL) עם שכבת רקע ניטרלית
  שמבטיחה שההיסטוריה תמיד קריאה גם כשאין אריחים.
- **Three.js** — עתידי, למצב ההליכה התלת-ממדי.

## הרצה · Running

```bash
npm install
npm run dev        # http://localhost:3000
npm run validate   # שער יושרת הנתונים (סכמה + מקורות)
npm run build      # בניית production
```

## תרומת נתונים · Contributing data

כל אלמנט חייב לעבור את `npm run validate`. הכלל: אלמנט שאינו `conjecture` חייב
לצטט לפחות מקור אחד קיים ב-`sources.json`. אם אין עדות — סַמנו `conjecture`
בכנות; אל תשדרגו ודאות. אם ציירתם צורה מקורבת — סמנו `geometryConfidence`
בהתאם (`approximate` / `schematic`), גם אם התאריך מתועד.
